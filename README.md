# maxapoc-infra

**Русский** | [English](README.en.md)

Ansible-конфигурация серверов проекта MaxApoc. Она настраивает Ubuntu 24.04, SSH и файрвол, Docker, прокси приложения, доступ для выкладки из CI, мониторинг и шифрованные резервные копии.

Цель проекта — одинаково настраивать тестовую и рабочую среды и воспроизводимо восстанавливать сервер после сбоя. Ansible управляет конфигурацией сервера, а новые версии прокси выпускает CI репозитория приложения.

- [Архитектура](ARCHITECTURE.md) — компоненты, связи и границы ответственности.
- [Подготовка сервера](ARCHITECTURE.md#setup) — требования, инвентарь и первый запуск.
- [Эксплуатация](docs/OPERATIONS.md) — выкладка, откат, резервные копии и восстановление.
- [Архитектурные решения](docs/DECISIONS.md) и [модель угроз](docs/THREAT_MODEL.md).
