# infra-lab

## Запуск с нуля

### 1. Требования к управляющей машине

- Ansible с `ansible-core` версии **2.18 или новее**.
  Минимальная версия определяется коллекциями проекта: `community.general` требует ansible-core >= 2.18, `ansible.posix` — >= 2.16, `community.docker` — >= 2.17. Подходит версия, которая удовлетворяет всем требованиям.

Проверить версию:

```bash
ansible --version
```

### 2. Требования к целевому серверу

- ОС: Ubuntu Server 24.04 (на другой ОС плейбук остановится на первой задаче с понятным сообщением).
- Пользователь с правами sudo.
- Установлен `openssh-server`.
- SSH-ключ управляющей машины добавлен этому пользователю:

```bash
ssh-copy-id -i <путь_к_публичному_ключу> <пользователь>@<адрес_сервера>
```

### 3. Настройка инвентаря

**`ansible/inventory/hosts`** — группа, алиас хоста и его адрес:

```ini
[infra]
infralab ansible_host=<адрес_сервера>
```

- `infralab` — алиас, по которому Ansible обращается к хосту. Его можно изменить, но вместе с именем файла в `host_vars/`.
- Имя группы `infra` менять нельзя: на неё ссылается `site.yml` (`hosts: infra`).
- Адрес сервера можно узнать на нём командой `ip a`.

**`ansible/inventory/host_vars/infralab.yml`** — переменные этого хоста:

```yaml
ansible_user: <пользователь>                 # пользователь с правами sudo
ansible_ssh_private_key_file: <путь_к_приватному_ключу>
common_swap_size_mb: 512                     # размер swap в мегабайтах
```

> Имя файла в `host_vars/` должно совпадать с алиасом хоста в инвентаре (`infralab` → `infralab.yml`), иначе переменные не будут подхвачены.

Порт SSH по умолчанию 22; если он другой, добавьте `ansible_port`.

### 4. Установка коллекций

Из папки `ansible/`:

```bash
cd ansible
ansible-galaxy collection install -r requirements.yml
```

Коллекции ставятся в `ansible/collections/` (задано в `ansible.cfg`, папка не хранится в git). Проверить:

```bash
ansible-galaxy collection list
```

Коллекции из папки проекта должны быть в списке первыми.

### 5. Запуск плейбука

Запускать **из папки `ansible/`**: Ansible ищет `ansible.cfg` в текущем каталоге, а в нём указаны инвентарь, роли и коллекции проекта.

Предварительный просмотр изменений (на сервере ничего не меняется):

```bash
ansible-playbook site.yml --check --diff
```

Применить:

```bash
ansible-playbook site.yml
```

При запуске Ansible запросит пароль sudo пользователя на целевом сервере (`BECOME password`).

Повторный запуск должен завершиться с `changed=0`: роль идемпотентна.
